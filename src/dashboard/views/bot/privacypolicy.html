1. Data Collected

We practice strict data minimization. The Bot collects and processes only the minimum data essential for delivering core bot features and maintaining server preferences:

badge Discord Identifiers

Discord User IDs, Server (Guild) IDs, and Channel IDs to associate user records, assign role configurations, and deliver command replies.

terminal User Input & Parameters

Command arguments, selected choices, and parameters supplied during slash command executions (e.g. custom clipboard text, search queries).

settings Configuration & Preferences

Custom user preferences (such as personal color roles) and guild-level server settings (such as auto-VC channels and prefix configs).

trending_up Gameplay & Leveling Data

Activity metrics, experience points (XP), virtual currency balances, inventory items, ranks, and leaderboard progression records.

security

2. Data Storage & Security

Storage Location: All collected data is stored locally in a secure, self-hosted database environment maintained and administered exclusively by the Developer. No unmanaged public database clusters are used.

Data Retention: Stored data is retained indefinitely to maintain seamless persistence of your server configurations, leveling milestones, and user profiles until a manual deletion request is submitted or the Bot service is permanently discontinued.

lock
Security Protocols

Access to production database records is strictly gated and limited exclusively to authorized maintenance procedures via authenticated secure tunnels.

share

3. Data Usage & Third-Party Sharing

Primary Usage: Your data is utilized exclusively to maintain gameplay mechanics, execute requested bot functions, and preserve server-specific settings across Discord.

No Third-Party Sales: Your data is never sold, rented, monetized, or shared with third-party advertising, data brokers, or marketing networks under any circumstances.

smart_toy
Bug Diagnostics & AI Analysis

In the event of critical system errors, uncaught exceptions, or database anomalies, anonymized error stack traces and relevant command input snippets may be processed via AI analysis tools strictly for debugging, troubleshooting, stability tracking, and code optimization purposes.

4. User Rights & Data Deletion

You maintain complete ownership of your privacy. You have the right to request a complete wipe of all your stored personal profiles, progression stats, and server records at any time.

mail How to Request

Join the Official Support Server or directly message the developer (_d6_) providing your Discord User ID (and Server ID if requesting guild data removal).

hourglass_top Processing Timeframe

Deletion requests are manually reviewed, validated, and processed within a reasonable turnaround window (typically within 48 to 72 hours).
