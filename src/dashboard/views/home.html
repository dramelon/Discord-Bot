Slash Commands

Browse core interactive commands you can run inside Discord

/help ▼

Displays a comprehensive list of all available commands, or retrieves detailed info and parameters for a specific command.

Parameters
command (Optional) - The specific command you want to learn about.
/ping ▼

Tests connection latency and response performance between the bot, Discord API, and hosting server.

Latency Diagnostics Returned
• Gateway Latency: Discord WebSocket connection heartbeat duration.
• Round-Trip Response: Latency between command execution and message response.
/clipboard ▼

Puts customized text and animated emojis onto a graphic clipboard/sign inside Discord chat.

Parameters
text (Required) - The message content to render. Supports custom server emojis.
/stretch ▼

Generates a wide-stretched distorted animation of your avatar or a target user's avatar.

Parameters
target (Optional) - The user whose avatar you want to stretch. Defaults to yourself.
/color ▼

Manage your personal role name colors and icons through an interactive button interface.

How to Use
Run the command to open the control panel. Click **Customize** to open a modal where you can input a hex color code or custom icon URL, or click **Remove** to clear your customized role styles.
/leaderboard ▼

Displays the server's top 10 users ranked by activity metrics, levels, and total earned XP.

/petpet ▼

Generates an animated petpet petting hand GIF of your avatar or a chosen user's avatar.

Parameters
target (Optional) - The user whose profile photo will be petted. Defaults to yourself.
/rank ▼

Renders your profile achievement card displaying server ranks, active level tiers, and current XP progression metrics.

Parameters
target (Optional) - Check another server member's active XP level and profile card.
/status ▼

Fetch the bot's health check summaries, hosting environment info, and WebSocket heartbeat indicators.

/vc ▼

Configure your dynamic voice channel parameters. Joining the main lobby automatically creates a private voice channel for you.

Channel Controls
Customize dynamic voice layouts, lock/unlock channels, set member limits, or rename channels via direct slash sub-commands.
